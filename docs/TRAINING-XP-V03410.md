# v0.34.10 历练双倍经验

用户确认将历练经验提高到原来的2倍。每场新结算的胜利及有击倒的败战，均先对本场应得经验乘2，再与该个体已有小数经验合并。各伙伴仍按自身等级、等级差及饱腹／心情计算；结果页展示全队实际到账总和。

例如20级对同级敌人，无状态加成胜利由7变为14XP；高饱腹、高心情时由7.7变为15.4XP，小数保留累积。20级升21级仍需400XP，同级无加成约需29次胜利。60级封顶，最后一级只发剩余所需经验并清零小数。

已发出的经验、旧完成成果及旧小数余额不翻倍。v17存档格式保持，进行中任务在升级后后续结算使用新倍率；已结算战斗不重复发奖。未完成战斗退出不发经验，一小时、后台继续、中途退出、状态消耗、金币／物品及其他玩法经验沿用原规则。

倍率唯一来源为 `assets/balance.json` 的 `training.xpMultiplier`；`tools/balance_catalog.py` 生成C宏及网页配置。固件实际历练结算和Web互动历练使用相同配置，野外／道馆倍率保持。

108组实际结算用例覆盖胜败、零／部分／全部击倒、1–3伙伴、照料与等级差、小数余额、满级截断、重复结算及保存重载，C ASan／UBSan与Web逐项相同。原有完整核心／Web、36组一小时轨迹及后台恢复、成长／旅行完成提示专项通过。

固定种子123、晨风草原、初始1级及高照料的主机一小时模拟：单宠原89XP／81场／结束3级，现211XP／81场／结束5级；三宠全队原204XP／62场，现429XP／64场。每场同条件按2倍计算，整轮总量还受升级后的敌级、胜败与战斗时长影响，不能保证整轮恰好2倍。这是可复现实验，不是设备或任意配队收益承诺。

发布包应用与PPASSET3均0.34.10，保留原0.34.9；当前未刷入设备，未重建Windows／Android。证据 `build/training-xp2-release-checks.json`。
