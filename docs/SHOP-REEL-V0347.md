# 逐格跑马灯与中奖闪烁 · v0.34.7

旧版按墙钟时间代入缓动曲线求格子，显示刷新较慢时会跨过中间格。按132ms间隔采样，八种奖品各出现7–10次不相邻跳转，旧证据见build/shop-reel-v0347-old-skips.json；此前只验证端点与换格数量，没有验证相邻顺序和慢帧。

新版用共享的离散时间边界推进：每次更新最多到下一格或下一次闪烁，跨过边界的时间不追赶。顺序0→1→2→5→8→7→6→3，外圈八个商品全部经过，中央为抽奖入口。转满三圈，再逐格走到已确定奖品；每步至少90ms，末八步110／130／150／170／190／210／230／250ms。理想时长按目标为3960–4590ms，慢刷新延长视觉时间。停奖后180ms一阶段，三次灭／亮，最后常亮并显示中奖提示、恢复操作。

core/shop_reel.h和web/shop.mjs共享assets/balance.json生成的配置，帧时间33ms保持。扣款／加库存仍在启动时一次性提交；旋转和闪烁只更新视觉，灭屏／浏览器隐藏暂停，禁止连点、购买和离开。不新增存档字段、图片、计时器或帧内读图。
