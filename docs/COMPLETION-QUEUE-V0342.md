# v0.34.2 历练与旅行完成提示

历练与旅行都结束后，亮屏先处理已经开始的历练升级／进化提示；最后一项确认后，接着显示「旅行完成」，点击「确认领取」才发放旅行金币、经验和藏品。没有升级的历练成果页也会继续提醒旅行。两份结果分别保留，不依赖打开页面时的先后顺序。

## 原因与修复

- 原生历练页33在刷新入口提前返回，同时不属于允许提醒旅行的页面。历练提示回到该页后，旅行完成无法继续展示。现在只有运行中的历练和未确认的成长选择阻止切换，已完成成果页可接上旅行。
- BOOT从其他页面返回场景，原先只要存在已完成旅行就设置持续暂缓，即便玩家正在处理的是历练。现在仅主动离开旅行完成／收获面板才暂缓该面板。重新进入旅行仍可领取或查看已经领取的收获。
- 普通自动进化原先可在熄屏期间创建遮罩，使亮屏后的旅行提示被阻挡。现在与历练成长提示一样，仅亮屏后展示。
- 没有更改奖励公式、任务期限或存档v17布局。历练经验仍逐场入账，成长提示只确认展示状态；旅行仍由核心原子领取并清除旅行者，重复亮屏和重进不重新发奖。
