# 场景内孵化窝避让

13 个场景从 `assets/scene-nests.json` 的真实窝位派生避让区域，空窝与带蛋的窝都参与。`tools/scene_nest_art.py` 同时输出 C 锚点和 Web 的 `scene-nest-anchors.mjs`，重建资源不会回退坐标。

`core/home_navigation.h` 和 `web/home-navigation.mjs` 使用同一整数规则。把窝的地面占用按 48px 宠物脚部范围扩张为宠物左上角禁入区：相对窝位 `[-34,-28,58,4]`。身体可以自然遮住远处物体，脚部不能落在窝内。合法目标吸附到最近的可行走边缘，最多六节点的可见图绕行；靠边的窝保留场景边界上的窄通路。路径与临时数组有固定上限，不分配堆内存、不消费游戏随机数、不写存档。

巡游采用封闭路线按路程匀速推进，避免端点投影后某一段过短导致走路姿态停滞。呼唤、探索、迎接、两宠互动与喂食共用绕行；原地摸摸和小跳保持原位置。神树保留两岸与祭坛前方路径，重返巡游的微小修正也经过碰撞检查。初次显示直接落在各自巡游相位的合法位置，避免追赶错位的起点时突然跳动。

窝本体已经画进场景，浅前沿始终由现有图片覆盖。蛋、光芒和窝沿按地面深度夹在远近宠物之间；宠物走到窝前会挡住窝沿和蛋，不再被固定顶层的蛋裁断。神树树冠与前方宠物保持原遮挡规则。小跳高度不改变脚下的地面深度。

验收包含所有场景的随机路线／边缘通道／整数取整、C/Web 精确对齐、巡游连续与活跃、24 个喂食点、真实 LVGL 五宠 38 秒巡游及呼唤／散步／小跳、实际兄弟层次、局部与完整刷新逐像素对比。Web 另通过实际 Canvas 绘制检查13景和390px减少动态布局。修复不改变蛋的固定位置、期限、资源图片或存档 v15；刷机另行执行。
