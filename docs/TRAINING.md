# 历练

当前版本 v0.34.15。当前数值规则见[轻养成规则](BALANCE-V0340.md)、[历练扩充](TRAINING-V0341.md)及[双倍经验](TRAINING-XP-V03410.md)。APP 第一页第一行中央进入历练，塔罗牌位于第三行中央。先选择场景，再从庭院选择 1–3 位清醒、健康且空闲的伙伴（仓库伙伴需先放入庭院）；选中顺序就是战斗接力顺序。

每轮固定一小时。返回 APP、长按 BOOT 回庭院、熄屏后继续历练；再次进入直接查看同一轮的画面、剩余时间、战斗次数、累计经验、金币和物品。已参加历练的庭院伙伴暂时隐藏，不能互动、护理、使用道具或参加其他活动；进行中可以定点替换未参战的空闲庭院伙伴；参战伙伴、旅行伙伴保持保护，收回／增减庭院人数仍需等待历练结束，以保护原个体索引。陪钓伙伴需先更换才能参加。一小时到期自动停止，伙伴回到庭院，保留结算页及具体物品清单；点击“再次历练”才开启下一轮。

历练进行中，底部中央返回图标仅离开页面，任务继续在后台运行；右侧门与向外箭头图标为“退出”。退出为薄荷绿实心图标；返回x158、退出x208，两者均44×44、y288同高并排，符合圆屏安全边距，探索、预警和战斗中都可使用。点击退出立即结束本轮，保留已完成战斗的经验和已发现的金币／物品；尚未完成的当前战斗不补经验，不补算剩余时间的奖励。伙伴立即回到庭院，显示本轮成果及实际历练时长，再按原规则提示升级／进化。退出不会再次发奖；网页保存失败时仍保持历练中，可重试。

「设置 → 历练设置 → 历练自动补给」，默认关闭，开关重启保留。开启后，搜索行进阶段及每场结算后自动检查参战伙伴：饱腹／清洁／心情低于40、健康低于30、精力低于20时，从真实背包库存补给。先用树果、肥皂、玩具、精力饼干，普通物品不足且仍有低状态时再用一份神树精华；药水已下架，不使用。恢复量沿用手动道具与节制塔罗加成，普通物品可连续使用到阈值，精华恢复五项至100。低精力已睡着的伙伴需要补至60才能醒来，例如精力19需要两块普通饼干（19→44→69）。

补给按编队顺序共享库存，不购买物品，不消耗未参战伙伴的道具目标，不改变当前战斗HP或回合。返回／熄屏／有效时间下的重启补算遵守同一规则，补给、扣库存与历练进度一起保存；发现成果仍显示实际拾取数量。没有对应物品或精华时，清洁／心情偏低仍可继续；若饱腹不足20、健康不足30、精力不足20或仍在睡眠，则结束本轮并保留已得成果。出发准入条件保持，需先满足清醒、健康30、饱腹20和精力40。

完成成果页以四块像素图标统计卡显示战斗次数、经验、金币和物品总数；下方三列图标清单显示具体名称与数量，最多九种，末行居中。零掉落显示空背包提示；标题保留本轮场景，完整一轮显示1小时，中途退出显示实际秒／分钟，继续使用虚化场景背景。再次历练及返回入口保持。图标为预制24px资源，原生进入时预载，动画循环不读图或缩放。

重启后，在 RTC／系统时间有效时按离线时长补算，最多补到本轮一小时。恢复期间分批推进，避免一次阻塞界面。进度、随机数、战斗血量／回合及已发奖励一同保存；中途再次重启保留尚未补算的时间。网页刷新及重新打开使用同样规则。结束时不为尚未完成的战斗发经验，已完成奖励保留，不会重复领取。

六景采用 360×120 横向条带，背景每秒向左移动 40px，宠物保持向右行进，步行动作 0.75 倍（两者均为 v0.33.67 的一半，33ms 目标绘制间隔，与旅行一致）。背景按单显示像素精度采样（25ms／px），33ms更新通常移动1–2px，视觉使用不足40ms的逻辑余数插值，避免重复画面和一次跳4px。途中每 6.4 秒短暂出现双斧、烟团和火花；这些装饰独立于游戏 RNG。寻找满五秒后每秒 25% 概率遇敌，第十六秒保底；敌人从右侧接近 1.8 秒，接触后感叹号两秒，然后与同一只敌人开战。每场敌队与己方等量，敌人物种不重复。

历练战斗在此前节奏上再快 1.5 倍，真实约 1.333 秒一回合；攻击、技能、血量与叙述使用 2.25 倍动作时钟，投球出场约 0.667 秒。正式道馆速度保持。原生共用道馆战斗组件，由历练独立33ms定时驱动，探索和战斗进度先推进、再绘制，避免相位落后一帧。条带局刷、预载 RGB565 及固定特效绘制命令保持；不在帧内读图、分配或重建场景。33ms 是目标间隔，不代表 ESP32 实测帧率。屏幕状态通知只在亮／熄屏切换时重置动画时钟；设备每50ms重复通知亮屏不会再截断反击。每轮先播放己方攻击、对方存活时再播放反击；命中显示伤害数字并扣血，归零后再换宠。原生回归包含50ms状态通知与33／66／99／132ms变化的渲染间隔，检查双方数字、扣血、交替及倒下换宠。探索统计框为x48／y229／264×57，三行依次为战斗经验、沿途发现、剩余时间与金币物品，均在框内。

每五分钟检查沿途发现：50% 找到5–8金币，10% 找到基础照料物品，40% 触发照料环境事件。药水已下架，新掉落仅包含树果、肥皂、玩具、精力饼干，权重45／25／20／10。奖励直接入账，金币／库存满时不溢出；掉落使用独立 RNG。环境事件及当前宠物池见[历练扩充](TRAINING-V0341.md)。

战斗自然结束即结算，每只选中伙伴按自己的等级与照料状态计算经验。从 v0.34.10 起，新结算历练经验提高到原来的2倍：基础胜利经验为 `2×(1+floor(0.3×有效敌级))`，有效敌级不超过该伙伴等级+3，再应用等级差及饱腹／心情系数。败战按胜利经验的20%乘以已击倒比例；零击倒为0。已有小数余额只保留一次，不翻倍已发奖励。等级上限60，升级需要 `20×当前等级`，到满级清空经验及小数。各伙伴实际到账值可能因等级、照料或满级截断不同；结果页汇总全队到账值。每场独立战斗血量，下场恢复，照料消耗与进化选择沿用原规则。

一小时结束后，为本轮实际升级的伙伴依次显示“历练升级”：宠物形象、昵称和 `Lv.出发等级 → Lv.结束等级`。每只升级提示确认后，达到当前形态进化条件的伙伴接入原进化选择与动画；多级升级可继续选择下一阶段，伊布仍先选择分支，道具进化仍需200金币。可暂缓或永久保持原样，永久拒绝沿用纯净之心规则。没有升级的伙伴不弹提示。

前台停留历练页时可直接显示；后台、熄屏或其他活动期间完成则保留提示，亮屏回到庭院／历练后继续。每只伙伴的已看状态随收据保存，重启保留未看提示，已看不重播。本轮庭院伙伴在原位置升级／进化；提示看完前不能覆盖本轮收据，原生也暂时锁定编队调整以保护个体索引。

`core/training.c` 管理单场战斗，`core/training_job.c` 管理一小时流程、掉落和检查点，原生独立 worker 在界面关闭后继续。当前存档为 v17，冻结 v16 及更旧布局并迁移；历练检查点不含指针，本次倍率更新不改存档格式。按固定 40ms 计算并保存不足一步的余数，不同前台刷新间隔、后台补算分块和多次重载得到相同结果。网页进度、经验、库存与金币原子写盘，失败时整批回滚并重试。
