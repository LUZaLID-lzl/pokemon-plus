# 野生伙伴（v0.33.41）

v0.30.0起排除144急冻鸟、145闪电鸟、146火焰鸟、150超梦、151梦幻；仅集齐八枚徽章后通过[神兽挑战](LEGENDARY_CHALLENGES.md)取得指定蛋。

有效地图累计1500–2500步 → 野生宠物头顶像素感叹号 → 60秒内点击打开遭遇面板 → 无时限确认 → 一对一自动对战 → 获胜收获 → 主动使用咕噜球 → 单次捕捉动画 → 成功结果。

| 项目 | 当前规则 |
|---|---|
| 出现位置 | 仅亮屏且庭院可见、已选初始伙伴、有可出战伙伴时生成；菜单、进化、其他战斗及地面照料中不生成 |
| 间隔 | 随机1500–2500个实际步数，约2000步；保存剩余步数，跨天／重启不重抽；地图13暂停累计 |
| 预告 | 真实形态以原生48px显示，头顶像素感叹号轻微跳动；保留60秒，未点击则消失；不自动弹框 |
| 提示 | 原生284px红白球形面板，显示真实形态、等级及默认出战伙伴；放走／对战均在球体内y254，含阴影不越过内沿；无可出战伙伴时禁用对战，不显示逃跑倒计时 |
| 确认 | 玩家点击「对战」才开始；自动选择场景内等级最高的可出战伙伴，同等级沿用场景顺序；不显示选宠箭头；可点击「放走」 |
| 超时 | 场景提示出现60秒未点击则消失；点开后不再自动逃走；不扣精力、不发奖励、不重建庭院 |
| 可出战条件 | 清醒、健康 > 0、精力 ≥ 10，且不在旅行；开始扣 10 精力 |
| 对手 | 前12张地图各自的地区池（含家庭进化形态）中随机选取；形态最低合法等级不超过当前可出战伙伴最高等级；始终 ≤ 60 级 |
| 战斗 | 一对一、四槽技能自动轮换；玩家先手，对手存活才反击；每 2 秒一轮（原3秒，1.5倍速），使用实际家庭技能与实际双属性 |
| 胜利 | 基础 25 金币，出战个体 30＋8×(对手等级−1) XP；收服对手的实际形态和等级 |
| 重复捕捉 | 同家庭可重复捕捉，生成独立个体；仍须使用1颗咕噜球 |
| 捕捉与奖励 | 胜利先领取基础金币／经验，点击捕捉才扣球、授予个体；动画与返回不会再次结算 |
| 容量 | 先放庭院，再放动态仓库；受实际存储空间限制。空间不足保留球与待捕捉结果，可腾空间后重试，不自动替换伙伴 |
| 失败／僵局 | 不授予宠物和奖励；双方无法结束时第 60 轮逃走 |
| 返回／恢复 | 返回庭院后战斗继续，庭院有继续入口；结果存档，收获页只展示，返回与重启不会重复发奖 |
| 等级封顶 | 出战经验遵守 Lv.60 上限，满级不再累计 XP |
| 存档 | 当前v13；已捕捉结果可恢复，只显示成功收据，不重播、不扣球、不再授予伙伴 |
| 网页 | 页面与动画来自共享LVGL实际导出；获胜示例中可买球、返回并主动捕捉，独立个体保存到浏览器试玩数据。与设备存档独立，不发设备奖励；「捕捉动画」示例按钮仅展示，不发浏览器宠物 |

未点击60秒期限与主动确认生效；打开面板后无时限，等待对战或主动放走。同家庭可重复捕捉以v12仓库规则为准。1500–2500步间隔、基础奖励、精力和回合参数集中在 `core/game.h` / `core/game.c`。本次没有新增图片BIN或修改硬件／Flash分区。

地区池、按孵化时所在场景的普通蛋、步数持久化与旧存档兼容详见[地区规则](PET_HABITATS.md)。v12布局保持，切页只移除提示对象，返回按同一只宠物继续，提示保留原截止时间，点击后取消逃走期限。

## 获胜与捕捉表现

- 获胜页参考进化界面：纯深蓝底、96px整数两倍真实形态、名称与等级、金币／XP数值。底部保留放走／捕捉按钮，球数合并在「捕捉 ×数量」中；无球时可购买后回到同一个待捕捉结果。
- 成功提交捕捉后播放约2.85秒：32px原生咕噜球抛物线 → 宠物淡入光中 → 球左右摇晃两次 → 属性色像素星光 → 开心动作成功页。无失败概率或再次扣球。动画期间屏蔽重复操作，完成后主动返回。
- 页面进入时创建固定对象池，33ms更新位置／透明度／常驻宠物帧；宠物严格按原生网格整数2倍采样、不新增帧内图像读取、不定时重建页面。切页取消表现，已保存的捕捉结果保持；重开直接显示成功页。
- Web使用单次播放 `docs/screenshots/wild-capture.gif`，完成切换静态成功页；减少动态效果直接显示成功。捕捉按钮的球数与捕捉／买球点击区域同步浏览器库存。
- `--wild caught`／`caught-ball`／`success`／`capture` 可导出无球获胜／有球获胜／已保存结果／实际捕捉动画；`tools/capture_wild_preview.py`生成真实截图、动图和分镜。

96px展示与进化共用既有有界ARGB画布（两个页面互斥）；按换帧更新并清理图像缓存，不新增另一份全图集／缓冲区。原生Flash资源及描述符不变。

v0.33.8按用户要求删除获胜／捕捉页副标题、回家引导、伙伴加入提示、森林背景、月桂与金色装饰。标题y47、宠物y118、名称y227与进化页一致；成功和失败均使用x125/y282、110×38的「完成」按钮。仅保留标题／宠物／名称等级／实际奖励／必要操作；不删掉状态失败等操作提示。
