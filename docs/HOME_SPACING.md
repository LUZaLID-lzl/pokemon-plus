# 场景伙伴间距 · v0.33.75

> v0.33.76 已按用户要求撤回下述避让、预留站位和转向逻辑，恢复之前的巡游。本页仅记录v0.33.75的历史实现与验证，不代表当前生效规则。

原巡游与互动路径只避开孵蛋窝，不检查其他伙伴的位置。各自路线交叉、呼唤同一片空地或喂食后恢复巡游时，会出现持续叠站。

`core/home_spacing.h` 与 `web/home-spacing.mjs` 同步维护最多五只伙伴的地面占位。横向间距小于40px且纵向间距小于28px视为占位重叠；使用地面坐标，不把跳跃的视觉高度或48px透明图片框当成落脚点。

- 入场、切换场景或伙伴重新出现时，寻找就近空位。正在移动的伙伴不通过瞬移分开。
- 巡游、呼唤与双宠互动逐像素检查移动段，保持窝、地形与伙伴间距。受阻时沿同一侧短暂绕行，无法通过则待机等待，避免原地踏步。绕行朝向随实际水平位移，纯竖向移动保留原朝向。
- 睡眠、按住与技能冲突中的伙伴保留原行为，其他伙伴避让它们。
- 喂食先为目标选择邻近空站位，并预留该位置。目标保留原2.4秒接近动作，其他伙伴避让目标及预留站位；这是消除持续叠站的规则，接近路线上仍可能有短暂的身体交错，跳跃的图像也可能有正常前后遮挡。
- 返回庭院的同时间戳重绘保持位置、朝向与待机／行走动画帧，不能把零时间重绘误判成堵路。

本模块只控制表现，不消费游戏RNG、不改变游戏奖励或存档、不读取图片、不创建帧内LVGL对象。C/Web共用参数并通过7800组逐字段一致性样本；13景×三种拥挤模式共468000次移动，覆盖集中出生、交叉路线与固定睡眠者。镜湖不可达的固定测试目标不作活动次数要求，仍检查地形与间距。

真实LVGL回归覆盖13景五宠巡游／呼唤／散步／小跳、24处喂食后继续巡游、菜单返回与睡眠恢复。1300帧局刷与全刷逐字节一致，检查无新增读图、奖励或存档变动。Web桌面与390px页面检查覆盖四宠巡游、呼唤／小跳、场景购买／使用成功直接回庭院及无存储变化；采样图像坐标时需排除同帧重复绘制和跳跃高度，不能将图像矩形相交直接判作地面占位失败。

场景背景恢复33ms采样（约30.3FPS目标），六区差分重绘；实际ESP32帧率与观感需刷入后验收。本轮打包但未刷设备。证据见 `build/scene-spacing-release-checks.json`。
