## 经验与可达性

上限60；每次升级需要20×当前等级经验，1→60共35400XP。满级不再累积经验，原存档中40级伙伴可继续成长。

| 途径 | 经验 |
|---|---|
| 普通挑战胜利 | 40＋10×出战等级 |
| 普通挑战惜败 | 10＋4×出战等级 |
| 旅行领取 | 20＋8×（出发伙伴领取时等级−1） |
| 野外胜利 | 30＋8×（对手等级−1） |
| 野外重复家庭／满员转换 | 额外60 |

## 存档与图片

存档仍v9，冻结v1–v8布局不动，旧物种／图片／技能ID均保留。精确旧版道馆HP及旧野外固定经验结果允许恢复；重赛使用新表，避免升级后把合法旧档判为损坏。未操作设备、NVS或执行刷机。

15950张BIN的PPASSET2资源包15115820字节，现有assets分区15138816字节，余22996字节。索引路径32字节、条目40字节；读取器兼容PPASSET1。相同负载可共享Flash偏移。新增头像无损索引化；宠物动作仍为原生Flash mmap，左右描述符常驻。

仅15张大型道馆地图／竞技场加入启动一次性解压，与原46张静态背景共61张；池内原图4178524字节，对齐后加最大11000字节ROM工作状态共4189528字节，低于4MiB。禁止把宠物帧改成帧内解压、文件读取或临时分配。宿主ESP分支实际逐项验证15950图、61张精确解码、稳定描述符和45秒巡游零额外读图／分配。
