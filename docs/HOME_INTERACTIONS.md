# 性格与场景技能冲突 · v0.33.40

| 项目 | 规则 |
|---|---|
| 容易动手的性格 | 固执、顽皮、淘气、急躁、浮躁（游戏行为映射） |
| 频率 | 在亮屏、场景内、无弹窗和操作占用时，每3–5分钟尝试一次，25%概率；全场最多同时一组 |
| 参与条件 | 至少两只清醒、未旅行、未使用道具、未被按住且未进行其他互动的宠物，精力至少30；发起者健康至少30，目标健康大于1 |
| 表现 | 停在原地面对彼此，发起者显示像素怒意与自身的一项有效攻击技能，随后出现对应属性的像素特效，目标短暂受击闪动；全程1.8秒 |
| 扣减 | 700毫秒命中时目标健康−3、心情−5，健康保底1、心情最低0；同一攻击只扣一次 |
| 中断 | 切页、灭屏、遭遇／赠礼、战斗、使用道具、目标入睡或被按住会中断；命中前中断不扣数值，返回不补发攻击。重新可用后等待新的3–5分钟检查，不追算离线攻击 |
| 状态与保存 | 健康和心情沿用个体原字段，通过revision持久化；攻击计时与局部随机数留在运行状态，不改v13存档布局，不消耗获取宠物／藏品使用的游戏RNG |
| 开销 | 复用现有攻击动作与场景粒子绘制层，最多16个局部小图元，不新增位图、帧内读图、动态对象或定时器；结束后从原地恢复巡游 |

Web镜像同一性格、概率、命中和特效规则，扣减仅保存在该浏览器的对应个体；隐藏网页与减少动态模式暂停此演示。动图：`screenshots/home-conflict.gif`。验证入口：`tools/test.sh`、`--home-conflict-smoke --frames-dir build/home-conflict-ui`。

# 场景伙伴互动 · 第一期（v0.33.19）

适用于庭院中的自家伙伴；野生宠物仍使用独立的感叹号／遭遇流程。设备、Windows、Android共用同一C行为和LVGL画面；Web资源工坊用相同规则，仍与设备存档独立。

| 行为 | 触发 | 表现 |
|---|---|---|
| 摸摸回应 | 额度内短按宠物，或BOOT批量摸摸 | 停步、朝向中央、开心动作、小幅跳动和像素爱心 |
| 呼唤伙伴 | 短按空白活动地面 | 附近一只清醒、健康且有精力的伙伴走来，停步回应 |
| 好奇探索 | 空闲随机 | 走到附近空位、左右观察、显示短暂问号 |
| 开心小跳 | 心情至少60、精力至少30的空闲伙伴随机 | 原画开心动作和最多4px离地，保持身体比例 |
| 伙伴打招呼 | 两只空闲伙伴接近，随机触发 | 走向相邻位置，互相朝向、先后回应，显示音符 |
| 结伴散步 | 两只空闲伙伴接近，随机触发 | 会合、一前一后出发，走一小段再恢复各自活动 |
| 并排休息 | 两只空闲伙伴接近，随机触发 | 找相邻位置安静停留，不改变实际睡眠状态 |
| 欢迎回来 | 离开庭院至少60秒再返回 | 一只清醒伙伴走向前方回应；两次欢迎至少间隔120秒 |

空白活动地面范围为点击中心x62–298、y135–248，宠物／蛋／道具／按钮优先，目标旁已有宠物时不触发呼唤；连续呼唤间隔至少900ms。神树镜湖自动避开树根与祭台，沿两岸及前后安全路线按路程移动；保留树冠前后遮挡。

自主单宠活动每20–40秒尝试一次，双宠活动每60–120秒尝试一次；至多一组双宠互动。精力低于30不参加自主互动；巡游仍走14.4秒，普通休息5.6秒、低精力休息9.6秒。精力跨过30时从当前位置开始新周期，避免周期变化引起瞬移。睡眠、旅行、健康为0、触摸按住或正在使用道具的个体不参加。野生提示、赠礼、道具或战斗期间暂停新增自主事件。

玩家触摸、睡眠或喂食会结束相关自主活动；双宠中一只被打断时双方都退出。动作结束后从最后位置恢复巡游，切页不跳回初始位置。菜单期间不累计场景动作时间；欢迎间隔使用实际经过时间。

每只个体每日20次短按规则保持：额度内沿用既有金币／心情／经验，耗尽后静默，不续播摸摸反馈；长按仍可查看状态。探索、呼唤、双宠活动、欢迎等均不发奖励、不消耗游戏RNG、不新增存档字段，当前存档仍v13。

实现复用待机／走路／开心／睡眠／进食图集；心形、音符、问号使用固定小图元，入场创建5个小绘制对象，帧内无新对象、图片读取或资源分配。没有新增宠物图片。

Web的「伙伴互动演示」提供八项预览按钮，仅播放动作；真实点击宠物仍遵守浏览器个体每日额度。减少动态时关闭自主行为及跳动，保留静态反馈。固件圆屏上不增加此演示控制区。

验证入口：

- `preview/build/pokemon_plus --assets sdcard/pokemon-plus --interaction-smoke`：真实指针呼唤、摸摸／长按、睡眠／喂食打断、欢迎冷却、连续位置及零新增读图／自动奖励。
- `--pat-smoke`、`--home-smoke`、`--wild-smoke`、`--travel-smoke`：每日额度、切页／道具、遭遇与旅行回归。
- `sh tools/test_scene_render.sh`、`python3 tools/validate_display_edges.py`：局部刷新与圆屏边缘。
- `python3 tools/capture_home_interactions.py`：八项真实LVGL动图及总览，输出`docs/screenshots/home-interactions.png`。

## v0.33.19：点击／喂食后停滞与朝向修复

- 旧巡游把当前位置作为新原点后继续叠加固定路线，再把越界坐标截到边缘；右下喂食落点可出现11.451秒播放走路但位置不变。现在按活动范围折返路径，保留连续位置，防止边缘“原地走”。
- 旧互动每帧先恢复初始朝向，再用本帧与上帧的整数坐标判断转身；慢速移动没有跨过一个像素时就恢复旧朝向，产生左右闪转。现在沿当前路径段确定朝向，零像素帧保持方向；已在会合目标上的伙伴等待时使用待机。
- 摸摸和小跳保持原位置，不投影到另一处镜湖坐标。互动被清理后从最后位置接回；互动期间不再逐帧搜索镜湖接回相位。
- 新增33ms慢速朝向回归、草坪九个边角／五个槽位／两种精力的连续巡游检查，以及真实LVGL全部24个喂食落点后16秒活动检查。本次实测走路且位置未变最长99ms；正常待机／睡眠不计为卡住。此前测试只检查最大位移，不能发现长时间没有位移，本轮补上活动性断言。

本版固件、Web、Windows和Android已同步。存档v13和每日20次奖励规则保持；本轮未刷入设备，实际设备表现仍待更新后验收。
