# 场景孵蛋窝

13个场景各有固定窝位。普通蛋、神兽蛋及旧存档中尚未孵化的蛋，共用当前场景的窝位；不改变孵化期限、摇动状态或存档v13结构。

## 图像来源

用户反馈独立窝图过于突兀，采用场景地面局部重绘；再次调整位置后，窝靠屋脚／树脚／岩脚，远离底部按钮和中央道路。MobiIoT编辑窝周围40×32原生像素范围，草地、沙窝、雪沿、岩缝、树根与窝共同成形。v0.33.24将城镇替换为林间瀑布，窝位于左侧岩脚干燥苔地；神树孵化点再左移30px，嵌入现有祭坛台面凹槽。原始场景保留；运行来源由assets/scene-sources.json统一指定，场景3／12使用source/scene-nest-terrain-v3，其他11景沿用v2。

原图、参考、提示词、模型及每次请求次数分别保留在assets/source、assets/reference、assets/prompts下的scene-nest-terrain-v2／v3目录及对应generation.json。瀑布全景原图与提示词在waterfall-v24目录，记录见assets/waterfall-v24-generation.json。terrainDirectory标识新增地面的生成目录，embeddedSources逐景指定实际运行来源；上一版及此前三个独立窝图集保留作溯源和位置参考，不叠加到最终背景。搬动窝必须从原始无窝背景重新编辑新位置，不能把含有旧地形的矩形块平移过去，也不能留下旧窝。

tools/scene_nest_terrain.py导入局部重绘，保持区域外景物的位置与形状；外围三档混色只在原生像素边界进行，窝细节不做模糊。为局部保留15色、原背景32色，合并最多48色，避免全图量化把小窝的内壁和前沿抹掉。使用统一背景对比度和最近邻3倍。不能用降低窝透明度冒充重绘地形。

## 蛋顶点阵光芒

v0.33.25起使用core/egg_glow.h／web/egg-glow.mjs的同一确定性采样规则。18个交错光点，从蛋上半部发出，在3px网格上向上与两侧散开，2.4秒循环、1.8秒寿命、先亮后淡，靠近蛋顶为3px方点，远处缩为2px。所有点底部不超过蛋y+12，不在蛋底或窝沿周围画放射线。普通蛋用奶白／浅金，神兽蛋用淡紫／冰蓝。Web减少动态时使用固定600ms采样。

固件复用一个84×64透明绘制对象和栈上定长采样数组，不增加图片、帧内资源读取或持久化数据，不消费游戏RNG。绘制区相对蛋为(-26,-44)，跟随摇动；窝前沿仍盖在蛋上，孵化期限、摇动规则和存档v13保持。tests/test_egg_glow.c检查上半部、画布、循环及13景圆边；mjs检查24个普通／神兽采样与C一致。tools/capture_egg_glow.py导出真实LVGL的完整2.4秒循环和3倍近景GIF。

## 资源更新流程

完整窝已画进场景。nest-fronts只从实际处理后的场景取72×15px前沿，二值透明，覆盖蛋底部5px；颜色必须与对应背景逐像素相同，不能再叠加独立图集的前沿。窝及周边承托区域不参加草木／水面位移动画。

修改后依次运行prepare_scene_nests.py、prepare_scenes.py、prepare_scene_motion.py、prepare_scene_effects.py、prepare_builtin_assets.py。完整prepare_assets使用同样流程。资源与应用PPASSET3版本须匹配。capture_scene_nests.py导出26张空窝／带蛋真实LVGL截图，并检查前沿吻合、3倍像素和圆屏安全范围；孵化smoke覆盖13景、菜单返回、期限与RNG不变和零帧内读图。
