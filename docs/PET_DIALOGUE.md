# 宠物对话与照料反馈

物品实际使用完成后，目标伙伴头顶显示对应图标和一句回应，持续3.6秒。六类反馈为树果、肥皂、药水、玩具、精力饼干和神树精华；精力使用既有闪电状态图标。图标24px、柔和亮底，气泡按12px字体的实际文字宽度自动伸缩：普通对白左右各8px留白，带图标时额外预留32px；总宽最多220px，超出后自动换行，高度至少44px。跟随伙伴居中，左右边界限制在x36–324的圆屏安全区域。睡眠中的伙伴也可显示收到照料的反馈，但不会因此额外醒来。蛋、孵化药剂和咕噜球保留各自流程。

111条独立台词分为28个上下文：8句日常、6句摸摸、各4句呼唤／欢迎、五类需求各4句、六类照料各5句、13景各3句。日常对白按健康、饱食、清洁、精力、心情的低值优先，阈值为30；状态充足时轮换当前场景与通用日常。摸摸、呼唤和欢迎回来触发相应回应，持续3.2秒。正在使用物品或已有对白时不插入日常台词。

每位伙伴、每个上下文独立轮换，带个体显示槽和形态偏移，同一上下文不会连续重复。固件换槽时保留原伙伴的轮换进度，新伙伴重置；Web按独立个体ID维护。轮换只存在内存，不消费游戏随机数、不写存档、不增加奖励或改变恢复数值。每日摸摸次数耗尽后不新增回应。已有冲突技能播报保留，并清除上一次照料图标。

唯一文案源为`tools/pet_dialogue.py`，运行后生成`core/pet_dialogue.h`和`web/pet-dialogue.mjs`，完整资源工厂也会生成。改文案后需执行`tools/generate_font.py`补齐设备中文字库。图片复用启动预载的icons-small及神树精华小图；气泡、文字和图标在庭院创建时分配，动画阶段不创建对象、读取新图片或缩放图标。

测试包括ASan／UBSan、111句唯一性、140000次轮换、1680个C/Web精确对照；共享LVGL的13景×6物品真实背包点击、完成反馈、圆屏位置、菜单返回、到期消失、936帧局刷与全重画一致及零额外帧读图。现有home／interaction／每日摸摸／照料和全套核心、Web测试已通过；固件编译通过。示例为`docs/screenshots/pet-care-dialogue.png`，本次未刷设备。
