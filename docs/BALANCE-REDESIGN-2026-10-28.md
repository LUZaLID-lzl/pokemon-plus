# 金币、成长、照料与遭遇数值重设计 · 讨论稿

日期：2026-10-28。审计基线：v0.33.79 的 core 实际代码；旧文档有历史数值，发生差异时本次以代码为准。

用户确认的方向：轻养成，每天上线 2–3 次、每次几分钟，约 3–4 周培养一支能挑战八馆的主力队；经验必须按实际战斗次数结算；增加场景野生遭遇。

本文保留最初规划与审计。已实施的v0.34.0规则以[BALANCE-V0340.md](BALANCE-V0340.md)为准；后续用户追加的繁荣度免费解锁、仅庭院伙伴历练已覆盖本文对应旧方案。表中“建议”均为初始调参值。只完成规则审计、现有核心对照和成长模型估算；未对新版战斗胜率、硬件体验或完整经济进行实测。

## 2. 推荐的整体循环

走路获得金币与遭遇 → 捕捉/孵化补充阵容 → 吃饭、清洁与休息准备出发 → 历练逐场获得小额经验 → 用属性搭配挑战道馆 → 徽章、旅行藏品与151图鉴提供长期目标。

每天以两轮最多一小时的后台历练为基准，间隔几小时恢复精力；后台历练不要求玩家持续盯屏。目标是每只主力每天约完成100–120场胜利，状态和地图正常时在约23–28天抵达后期等级。日常战斗胜率不足、步数少、组队较晚会延后；此时应改善配队/难度，而不是奖励连续战败。

## 3. 等级与逐场经验

### 3.1 保留成长曲线

保留等级上限60、升级经验 `N(L)=20L`、现有进化等级。Lv.1到60累计需要35400 XP。无需通过改动旧宠物等级解决新产出过量。

### 3.2 历练每场奖励

对每位编队宠物分别计算：

```
L = 这只宠物在战斗开始时的等级
E = 敌队平均等级
有效敌级 = min(E, L+3)
基础胜利经验 B = floor(1 + 0.30 × 有效敌级)
实际胜利经验 = B × 等级差系数 × 饱腹系数 × 心情系数
```

- 正常结束一场胜利才发经验；搜索、接近、播放动画、等待、未完成退出均不发战斗经验。
- 1–3只编队成员各算各的奖励，不把三宠经验除以3。单宠专练升级更快，三宠同时培养的总经验更多。低级被带练时按自身等级+3限制有效敌级。
- 敌级比自己低0–5级：100%；低6–10级：50%；低11级以上：20%。越级奖励不再无限增加。
- 失败奖励为 `胜利经验 × 20% × 实际击败敌宠数/敌队人数`；没有击败任何敌宠则为0。不能靠一直送败升级。
- 小数按个体累计结转，凑够1XP入账，不对每场向上取整；退出、换队、重启不清零，也不能反复领取。
- 结算明确显示“第X场胜利 / 本场每只+Y XP / 距下一级还差Z XP”，不显示按挂机分钟发放的经验。
- 先维持逐场体验，不额外设置“每日经验到上限就归零”；通过精力、补给与低级地图衰减约束收益。

同级、满状态加成之前的直观目标：

| 宠物等级 | 下级所需XP | 同级胜利基础XP | 从空经验条升级约需胜利 |
| --- | --- | --- | --- |
| 1 | 20 | 1 | 20场 |
| 5 | 100 | 2 | 50场 |
| 10 | 200 | 4 | 50场 |
| 20 | 400 | 7 | 58场 |
| 30 | 600 | 10 | 60场 |
| 40 | 800 | 13 | 62场 |
| 50 | 1000 | 16 | 63场 |
| 59 | 1180 | 18 | 66场 |

例：20级打同级敌队，原来每场138XP，建议改为7XP；50级原来318XP，建议16XP，约为原来的5%。若保持当前场次数量，一小时通常约一段经验条，而不会连续升十多级。

新手敌人也需要更合理：保留六张等级地图，敌级在地图区间内，优先抽队伍中位等级±2，最后裁切到地图上下限；避免1级新手刚出发就主要面对10级敌人。战斗速度不为控制经验而故意放慢。

### 3.3 其他经验入口同步对齐

| 入口 | 建议经验 | 用途 |
| --- | --- | --- |
| 野生遭遇胜利 | 实际出战者2B，B使用同样的敌级限制和状态系数 | 鼓励主动参与，避免遭遇增加后成为经验洪水 |
| 道馆普通胜利/再战 | 全部编队各3B，B取敌队均级，沿用等级差和状态系数 | 三只敌宠比普通单场奖励高，配合更高精力消耗 |
| 道馆首通 | 普通胜利奖励外，每只编队额外获得当前等级经验条的30% | 一次性的阶段奖励，不再一次连升数级 |
| 道馆失败 | 普通经验×20%×实际击败数量/3 | 有实质进展才有少量经验 |
| 旅行 | 出发等级经验条的20%/三小时，仅旅行个体 | 主收益改为藏品，经验作陪衬；出发时锁定基数 |
| 计步0–5000步 | 每1000步庭院每只获max(20,当前经验条的6%) | 新手保底、后期每日约30%经验条 |
| 计步5001–10000步 | 每1000步每只获当前经验条的2% | 额外最多约10%经验条；超过10000步不再发经验/金币 |
| 摸摸 | 每个体前5次各1XP；第6–20次只恢复心情 | 不要求每天100次点击才拿满成长奖励 |
| 普通照料道具 | 不发经验 | 杜绝为了升级反复给满状态宠物喂便宜物品 |
| 医院/钓鱼/挖宝/神兽蛋挑战 | 不额外发经验 | 保持玩法分工，神兽胜利仍奖励对应蛋 |
| 旧单宠挑战入口（如保留） | 统一按B发放，移除40+10L的旧奖励 | 避免遗漏的旧入口成为最高效练级来源 |

计步奖励按每个实际跨过的1000步门槛结算，避免月底统一领取产生不同结果；塔罗“星星”的建议效果改为计步经验+10%，不再每100步固定+1。

## 4. 五项状态分别解决一个问题

五项仍为0–100。日常60–80就能正常玩，80以上有小幅准备奖励；不要求五条始终100。

| 状态 | 建议作用 | 自然变化与主要恢复 |
| --- | --- | --- |
| 饱腹 | ≥80，战斗XP+5%；20–39，XP×80%；<20不能开始历练/旅行 | 庭院每小时-1；树果+40 |
| 清洁 | <40时历练额外健康-4/小时；<20时-8/小时，两档不叠加 | 庭院每2小时-1；肥皂+50；不直接制造伤害加成 |
| 健康 | ≥80战斗HP100%；60–79为90%；30–59为80%；<30不能出战或远行 | 不自然下降；战斗倒下/脏污导致下降；医院、药水恢复 |
| 心情 | ≥80，战斗XP+5%；<40，XP×90%；不强制拒绝玩家操作 | 庭院每2小时-1；每次摸摸+2，最多20次/日；玩具+35 |
| 精力 | 历练出发≥40；低于20时完成当前战斗后返程 | 在家/仓库空闲+10/小时；睡眠+25/小时，60醒来；精力饼干+25 |

饱腹与心情正向加成相乘后封顶110%，防止塔罗、状态、活动奖励层层放大。药物治疗不改变个体原始HP数值，健康只影响本次战斗可用HP。

### 4.1 历练与其他活动的损耗

| 行为 | 建议消耗 |
| --- | --- |
| 历练每完成一场（胜负均算） | 每位编队精力-1 |
| 历练每累计10场 | 每位编队饱腹-1 |
| 历练每累计20场 | 每位编队清洁-1 |
| 任何战斗中某个体倒下 | 该个体健康-1；战斗HP与健康仍是两套数值 |
| 道馆每次挑战 | 每位编队精力-5，饱腹-1；不重复叠加历练的场次损耗 |
| 野外每次开战 | 实际出战者精力-3；增加遭遇后不再沿用每场-10 |
| 三小时旅行 | 总额外饱腹-6、精力-15，返回心情+10 |

满精力宠物可完成约80场历练后需要休息；常规每轮约50–65场胜利，加上失败可能60–80场，第二轮应相隔约6–8小时，或使用补给。返回/重开不补精力，不清除10场/20场的个体损耗余数。低状态导致返程须说明原因并保留已得奖励。

活动中的宠物不享受空闲精力恢复；仓库历练同样承担上述损耗。仓库不额外消耗饱腹/清洁/心情，保存原状态，只恢复空闲精力；换仓不会把四项补满。让仓库伙伴接受道具时提供明确选宠入口，避免只能把它上场才能照顾。

### 4.2 离线保护

- 离线被动衰减最多补算8小时；只由该次被动衰减产生的饱腹/清洁最低20、心情最低30，原本更低的不抬高。
- 健康不因长时间未登录而继续下降，不死亡、不丢宠物。
- 已出发历练/旅行按实际完成的活动扣除消耗，不能借离线保护免掉活动成本；离线最多补到已开始任务的终点，不自动开始第二轮。
- 不靠手机通知催玩家喂饭；主场景用缺失状态小图标、宠物信息页给简短作用提示。

## 5. 医院的职责缩回健康

| 服务 | 建议 |
| --- | --- |
| 免费爱心小游戏 | 成功后将合资格庭院伙伴健康提高至至少60；更高的保留 |
| 不再恢复的项目 | 饱腹、清洁、心情、精力；不强行唤醒睡眠者 |
| 精细治疗 | 20金币/只，健康补至100；玩家明确选择个体 |
| 重复免费治疗 | 永远只保底到60，不累计成70/80/100，不产金币/经验/道具 |

这样医院仍能救急：没钱也能恢复到可出战状态；想有完整战斗HP，可以付费治疗或使用药水。其他四项各自需要吃饭、洗澡、互动、休息。

掉落统计必须将现金、件数分别呈现；不把发现次数当作金币件数，不把原商店价作为“实际挣到金币”。每日额度采用可靠日期高水位，倒拨时间不能重置。

## 8. 增加场景遭遇

不只把阈值调低，还要解决“走够了，但没及时进庭院就没有第二次”的问题。

| 参数 | 当前 | 建议 |
| --- | --- | --- |
| 实际步数阈值 | 1400–1600，均值1500 | 400–700，均值550 |
| 非步行兜底 | 无 | 亮屏庭院有效活动累计20分钟，补一次待遭遇；与步数门槛谁先到取谁，两项同时重置，避免双发 |
| 待遭遇储存 | 最多1次 | 最多3次；显示中的一只也占一个额度；满额后不继续累计下一轮 |
| 同时显示 | 一只 | 仍一只，不让宠物挤满圆屏 |
| 未点击提示 | 60秒 | 180秒有效庭院可见时间；菜单/熄屏暂停；已点击仍不限时 |
| 下一只出现 | 重新走一轮 | 有待遭遇时，上次战斗/捕捉/放走/超时结束后60秒有效庭院时间再显示 |
| 切图 | 未点击个体放走 | 建议保留已抽定个体；未生成的待遭遇按下一次显示时的地区池抽取，禁止切图重抽同一个体 |
| 未拥有偏好 | 地区合法池内随机 | 有未持有家庭时50%从未持有家庭池选，50%从完整地区池选；以庭院+仓库现有家庭判断 |
| 神兽/地区 | 地图1–12地区普通池；神兽专属 | 保留；第13景不消费普通待遭遇次数，不把神兽加入普通池 |

5000步理论上可跨过约9个门槛，实际看到的次数取决于登录时机和3次缓存容量，不能声称每天必遇9只。短暂登录2–3次的体验目标是每天实际参与3–6次，连续散步后回来可依次看到最多3次。没有步行的玩家靠庭院活动也能遇见，纯熄屏不产时间兜底。

捕捉仍需先战胜、再用球，允许主动放走；每次只处理一份结果，不自动弹出战斗。现有按主力等级附近抽野生等级可暂保留，捕获不抬高最高等级，不另加战斗外经验；继续观察“捕捉替代低级孵化培养”的比例。

## 9. 成长节奏估算与验收目标

用于估算的模型：三只同级主力从1级一起培养；每只每日100或120场同级历练胜利；平均状态经验加成5%；5000步、各摸5次；账号每天一次旅行轮换最落后主力；三次野生胜利平均分给三只；到达各馆对应最高敌级时模拟领取首通30%条奖励。小数经验结转。失败经验、首通常规战斗经验与额外玩法未计入。

| --- | --- | --- | --- |
| 12 | 第4天 | 第4天 | 第一馆等级附近 |

这是等级里程碑，不是已经验证的道馆通关日。真正通关还受属性、招式、健康、性格、IV和阵容接力影响；当前道馆对手并非全部按玩家统一公式生成，需要单独跑胜率。新账号也需要组齐三只主力，组队时间会使进度略后移。

敏感性：每日80胜约31天到60，130胜约21天。实际三宠每小时有效胜利若低于50场，先检查敌级分布与胜率，不承诺仍在四周内。方案落地前至少验证：

- 六景、1/2/3宠、同级与混级、优势/劣势属性各连续运行，记录小时胜负数、每只实际到账XP、等级及状态成本；目标普通三宠每小时约50–60胜，极端属性组合允许主动换队。
- 同级普通历练的中性队伍胜率目标75–90%；若明显偏低，应调敌方数值/配对而非发更多失败经验。
- 道馆推荐等级附近，普通有效配队、状态60–80的首通胜率目标50–70%，克制队75–90%；不能靠医院保底健康就无脑碾压八馆。
- 24小时账号现金流包含所有入口，分别检查不走路/5000/10000步、1/2/4轮历练、免费/付费医疗与小游戏重度玩法。
- 野生遭遇测量“生成/显示/点击/战斗/捕捉”五层转化，目标未点击丢失率<20%，常规日实际参与3–6次。
- 任意中途退出、切页、换仓、重启、后台补算、跨日不多发经验/金币、不少扣消耗；战斗加速只改变实际完成场数，不能改变单场公式。

建议记录指标：每日每宠等级增长、每来源XP占比、每胜XP、胜负与耗时、金币净增与余额分位、各道具用量、医院免费/付费次数、五项低值停留时间、遭遇漏看率、主力第三只与首只等级差。不需要上传联网，先用本地模拟记录与自愿试玩表评估。

## 10. 个体属性与存档实施边界

- 第一轮保留25种性格、IV0–31、当前基础战斗属性与属性克制；先接入健康对可用HP的影响，避免同时改物种基础值而无法定位效果。
- 速度当前未决定先手，界面应说明其现状；“按速度决定先手”属于后续独立战斗改造，暂不叠加到这轮经济估算。
- 同种宠物的个体差异、不同物种基础属性差异可后续单独设计；不增加洗IV/重抽性格的付费循环。
- 保留老存档等级、宠物、已获金币/藏品/徽章/道具。新公式从新完成的战斗生效；升级过程中未结算任务要锁定出发规则版本，不能重载后换公式重发。
- 逐个体经验小数、场次消耗余数、空闲恢复时间、每日账号摸摸/钓鱼/再战计数、待遭遇3次与提示可见计时都需要明确持久化方案。不能假定现有v16可直接原样复用，更不能修改已冻结的旧布局。
- 若确定实施，应集中到一份数值配置，派生C/Web并做一致性检查，再构建同版应用/PPASSET3；本讨论稿不变更运行版本和资源包。

推荐实施顺序：先改逐场经验及所有旁路奖励 → 医院与状态消耗/恢复 → 遭遇频率和缓存 → 经济入口与每日预算 → 完整成长/胜率验证。四项应在同一平衡版本联合验收，防止只削弱经验却留下免费全恢复和刷钱旁路。
