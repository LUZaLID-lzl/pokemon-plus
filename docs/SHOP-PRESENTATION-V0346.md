# 商店排版与抽奖图标 · v0.34.6

外圈八种商品保留九宫格位置及40px图片，移除常驻实色底板与边框。商品名称与金色售价合并为一行，使用独立10px字库，名称左对齐、价格右对齐，四字名称与三位价格之间仍有间距。每格72×64，起点(64,98)、列距80、行距68；图标在格内(16,2)，文字在y49。普通商品不重复显示金币图标，标题余额与中央抽奖价格保留金币图标。
