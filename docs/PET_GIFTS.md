# 场景宠物赠礼

v0.31.2文案：标题「发现藏品」，宠物描述「{名字}找到了藏品」，确认按钮「收下藏品」；网页入口「宠物发现」。

v0.31.1布局：球体和圆扣对齐屏幕中心，标题、宠物、名字、藏品、品质、按钮沿竖直中轴排列，两侧星芒和分隔线对称。

清醒、健康值至少30的场景内宠物有小概率找到藏品，用咕噜球样式的弹框赠送给主人。弹框展示宠物原生48px头像、藏品32px图片、藏品名称与品质，点击「收下藏品」回到原场景。

- 累计停留在亮屏场景内的有效活动每600秒判定一次，成功率5%；平均约200分钟有效活动遇到一次，实际时间随机。多只宠物共享判定，数量不叠加概率。
- 无初选、进化弹框、战斗、野生相遇、道具使用或挖宝时才计时；睡眠、健康不足、正在旅行的宠物不参与。其余健康的留守宠物仍可赠礼。
- 熄屏、菜单、商店、离线不累计；超过5秒的异常更新也不补发或批量抽奖。进出页面不重抽、不重置累计计时。
- 从583件普通旅行藏品中均匀选择一件未拥有的藏品。品质沿用普通60%、精良25%、稀有10%、史诗4%、传说1%的目录分类；随着未拥有池减少，实际获得比例随剩余藏品变化。
- 不赠送特殊藏品「纯净之心」，全部583件集齐后停止赠礼，不替换成额外资源；旅行集齐后的金币与经验规则保持。
- 发现时将藏品与待确认收据一起原子记录，弹框确认只关闭收据。待确认时不产生第二份礼物，也不会产生新的野生相遇；切页、离线、重启后仍展示同一份礼物，永不过期，不重复授予。
- 场景、动作、宠物位置不因礼物弹框重建；静态图元只在弹框出现时创建，持续显示不读图或重建。使用现有宠物与收藏图，无新增图片BIN。

存档升级v11，`core/legacy_game_v10.h`冻结v10布局；读取save_v11，缺失时依次迁移v10至v1，保留旧NVS key和原有宠物、候补、成长、徽章、收藏、神兽蛋等状态。

网页「宠物赠礼」展示共享LVGL截图，点击确认回庭院，仅为固件界面示例，不向浏览器收藏或设备存档发奖。图见[screenshot](screenshots/gift-pending.png)。
