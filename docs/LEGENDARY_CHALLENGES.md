# 神兽挑战

第一代的四只传说宝可梦，加上幻之宝可梦梦幻，统一作为本游戏的五只神兽。分类依据：[PokeAPI species 数据](https://raw.githubusercontent.com/PokeAPI/pokeapi/master/data/v2/csv/pokemon_species.csv)，核对记录保存在[分类记录](legendary-classification.json)。风速狗的图鉴分类名称、快龙的强度、百变怪的特殊能力均不构成传说身份。

| 全国编号 | 名称 | 分类 | 游戏获得方式 |
| --- | --- | --- | --- |
| 144 | 急冻鸟 | 传说 | 八徽章后挑战，胜利获得急冻鸟蛋 |
| 145 | 闪电鸟 | 传说 | 八徽章后挑战，胜利获得闪电鸟蛋 |
| 146 | 火焰鸟 | 传说 | 八徽章后挑战，胜利获得火焰鸟蛋 |
| 150 | 超梦 | 传说 | 八徽章后挑战，胜利获得超梦蛋 |
| 151 | 梦幻 | 幻之宝可梦 | 八徽章后挑战，胜利获得梦幻蛋 |

指定蛋是本游戏的自定义玩法；正作中这五只不参与普通繁殖。

## 界面（v0.30.1）

五张神兽卡片采用对应属性色，八段徽章条显示解锁进度。未解锁时保留灰紫精灵和像素锁；获得胜利后显示标记和「已胜利」。详情上方并列神兽与奖励蛋，下方横排选择伙伴；金框和名字／等级显示当前出战个体。获胜页显示对应蛋及实际背包数量，失败页说明本次无蛋。

装饰使用静态LVGL图元，复用原生48px精灵与蛋图，无新增图片包。网页使用相同渲染截图，支持锁定、解锁、已胜利、单伙伴／五伙伴及结算示例。[查看界面](screenshots/legend-design-preview.png)。

## 进入与战斗

APP第一页面保留原九项，通过底部箭头进入第二页「神兽挑战」。只有获得八枚徽章（位图255）才能开始。未集齐时可以查看五只目标与伙伴选择，开始按钮禁用，核心接口也检查门槛。

五只对手均为Lv.60，HP356。玩家选择一只清醒、健康且精力至少10的庭院伙伴，进入真实一对一回合战斗，使用该形态的技能威力及双属性相克，消耗10精力。旅行、其他战斗、掉落道具、野外待确认或结算、挖掘期间不可开始。切到庭院后可继续同一场挑战，末击动画完成后显示结果。

每次胜利获得对应蛋1颗，进入背包，标记该目标已胜利；可重复挑战。挑战不直接添加宠物、不发金币或经验。失败无蛋。满宠物栏仍可获蛋；对应蛋库存达到65535时拒绝开战。奖励与结果状态一起保存，回到菜单或重启不会再次领取。

## 背包与孵化

背包「神兽蛋」页签显示五种独立库存。玩家选择一颗才消耗并放到当前庭院：

| 条件／动作 | 结果 |
| --- | --- |
| 场上已有蛋，或游戏忙碌 | 拒绝放置，不扣蛋 |
| 庭院5位＋候补11位全满 | 拒绝放置，不扣蛋 |
| 庭院满、候补仍有位 | 可放置，孵化后进入候补 |
| 成功放置 | 消耗对应蛋1颗，场景显示名称及倒计时 |
| 摇动启动且达到随机2–4小时期限 | 精确孵化对应神兽，Lv.1 |
| 使用已有孵化药剂 | 消耗药剂1瓶，精确立即孵化对应神兽 |

普通蛋仍优先缺失家庭，在74个普通家庭内随机，不能抽中五只神兽。场景遭遇候选与确认开战均排除它们。查看工坊图片或预览示例不会授予浏览器宠物。

## 存档和资源

存档v10追加五种蛋库存、胜利位图、当前挑战目标及当前孵化目标；冻结v9结构，原存档字段保持前缀兼容，旧key保留。已有神兽伙伴保留；v9未结算的神兽野外预告／战斗取消，不能借旧遭遇继续捕获。已结算旧奖励不撤销。

复用已有151形态资源库、头像与蛋图，无新增图片BIN、分区或硬件改动。网页同步APP分页、锁定／解锁、五只目标、真实战斗GIF、获胜／失败、背包五种各1颗的示例、指定蛋与孵化截图。Web只切换明确标注的固件画面示例，不修改localStorage、浏览器图鉴或设备NVS。
