- **独立 LCD 模组参数 PDF：无法确认。** 官方资料页目前可找到板级原理图，但它不是独立屏幕规格书。不补写未知模组电压、极限时序、其他屏幕初始化表；此部分停止修改。
- **实物修订版、LCD ID、触摸坐标精度、色彩和运行性能：无法确认。** 当前只编译与电脑验证，未知 ID 拒绝回退。
- **POWER 的 GPIO：不存在可用的软件短按接口。** 原理图 Key1 接 U6 ECJ23001-4FCBD6 的 KEY 脚；官方产品页明确说 PWR 不支持自定义。使用 BOOT 单击控制背光；不会编造 POWER GPIO。
- RTC 自 v0.33.14 接入，见下节；没有确认可靠时间前不结算断电离线时长。音频、OTA 未接入。电量显示按用户2026-10-26要求恢复；硬件依据与只读采样见下节。

## RTC 保时（v0.33.14，2026-10-26）

原理图 U5 为 PCF85063ATL，共用 BSP I²C 总线；RTC_VDD 由 U16 XC6206P332MR 从 VBAT 稳压供电，独立于屏幕主电源。电池保持供电时可脱离 USB 走时；RTC 也完全掉电后须重新校时。没有额外假定存在纽扣电池。

`main/rtc_clock.c` 初始化只注册设备句柄，不复位或写控制寄存器。开机读取控制和连续七个日期寄存器，拒绝停振标志 OS、STOP／测试／12小时模式、非法 BCD／日期及2025年前或2100年起的时间。RTC RAM字节0x03以0xA7标记本项目格式，拒绝未经校准的出厂／旧固件本地时间；首次需USB或联网校时一次。RTC 以 UTC、2000年为年份基准保存，界面通过既有 CST-8 显示北京时间；不使用厂商辅助函数的1970年份约定，避免闰日误差。

USB 或 SNTP 校时后，通过原子标记交给主任务、在显示锁外写回 RTC；STOP→连续日期写入→恢复运行→读回核验，CAP_SEL 沿用官方12.5pF配置。I²C 超时20ms，失败每30秒重试，日期写入中途失败保持 STOP 以防下次启动误用半写入日期；不周期性写入或增加 Flash 存档频率。`core/rtc_time.c` 负责不依赖时区的日期转换，主机测试覆盖全部2025–2099日期、闰年／2038／时区、停振／无效日期及传输失败。

## 板载指示灯判读（2026-10-28）

Rev1.1原理图中LED1位于BAT CHARGE区域，经R4接至ETA6098的STAT脚；LED2位于DC-DC区域，由3V3经R1供电并接地，是电源指示。两灯是独立电路，均不是应用可控制的RGB灯。该原理图未注明实装灯珠颜色，不可直接套用“红灯充电／绿灯充满”或将用户观察到的绿色熄灭、剩余红灯认作同一灯变色；需结合实物位置识别。BQ27220读取到的SOC与屏幕动画不能代替ETA6098实际充电状态测量。

自v0.33.80起，充电且有效SOC<100时，在电池轮廓内部增加小闪电，暖金色核心配深色侧描边，覆盖于原六步填充之上。拔线、满电或读取无效时隐藏；不增加I²C读取，不改变原充电状态判断及15秒采样。Web与原生预览已验证；后续已按用户授权刷入v0.33.80，程序／资源匹配、存档保持及USB／RTC同步和重启恢复通过。首启SOC81%、电流528mA，符合充电闪电条件；未作实体屏幕目视验收。

## 电池电量读取（2026-10-26，恢复）

按用户最新要求，恢复编译main/battery_monitor.c及core/battery.c；主场景BAG按钮下方显示电池图标与百分比，设置新增“显示电量”，默认开启。使用独立hud_display_v2保存三项显示位；旧hud_display只迁移时间／金币偏好，并默认加上电量位，旧键保留。

官方 Rev1.1 原理图 U13 为 BQ27220YZFR，使用既有 SDA/SCL。地址和标准命令来自官方示例锁定的 `espressif/bq27220 0.1.1`（`managed_components/espressif__bq27220` 的 `bq27220.c`、`bq27220.h`、`priv_include/bq27220_reg.h`）：7位地址0x55，SOC 0x2C、BatteryStatus 0x0A、OperationStatus 0x3A、Current 0x0C，双字节小端。

`main/battery_monitor.c` 复用 `bsp_i2c_get_handle()` 和 BSP 配置的总线速度，只注册一个设备句柄；每15秒在显示锁外读取，单次命令超时20ms，任一读取失败即停止本次采样。没有调用会解锁或写入电池配置的初始化函数，不改容量、化学模型或校准值。

SOC须在0–100、BATTPRES为1且INITCOMP为1才有效；否则显示暗色空电池和“--”，不沿用失效的旧百分比。充电状态要求电流为正、DSG和FC均为0，使用暖色指示；低于等于20%显示低电量色；满电可显示100%而不显示正在充电。使用电量计报告值，不从电压猜测百分比。已通过主机模拟传输/解码和固件编译，电池存在检测、充电方向及SOC准确度仍须实机确认。

自v0.33.54起，充电且SOC<100时，底部电池暖金色填充按0／2／4／6／8／10px逐步循环，每300ms一格，百分比保持真实SOC。复用场景计时器，步进时仅更新原10×5px填充对象；隐藏电量、离开场景或灭屏暂停推进。拔线后按实际电量恢复，满电静态全满，无效读数静态灰色空电池；继续每15秒采样，不额外访问I2C。Web预览可用`?battery=72&charging=1`，减少动态时固定充电图标。原生六步／局部刷新与状态切换、浏览器及同版固件包已验证，尚未刷入设备。


## 触摸漏点与移动撕裂排查（2026-10-23）

用户实机反馈多数按钮需要多点、宠物移动时上下错位。后一现象符合屏幕撕裂特征，不能仅归因于刷新率低；尚未测量面板扫描频率，也未将本次修改刷入验证。

官方Rev1.1原理图J3的TE18对应`LCD_TE(GPIO18)`，见本地原理图提取文本345–397行；原厂ST77916初始化表已有0x35/0x00开启TE。原BSP默认撕裂模式NONE，50行双PSRAM绘图缓冲；原适配器在LVGL读取回调中访问触摸，用二值IRQ信号量，绘图繁忙时短点击的按下/松开可能合并。当前LVGL刷新目标33ms不等于实测屏幕刷新率。

应用`main/display_port.c`继续通过原BSP初始化LCD/CST816S，不改上游源码、寄存器表、总线频率、极性或坐标变换。触摸独立任务由IRQ唤醒，按住时10ms读取移动/松开，16边沿队列保留完整短点击；松开后停止空闲I2C轮询，避免休眠触摸芯片持续报错。短暂I2C错误保持原状态，连续100ms读取失败强制松开；关屏/唤醒清队列并忽略已按住的接触。LVGL每10ms消费，页面重建后的下次按下先刷新布局，防止命中旧坐标。

绘图改为一块360行容量PSRAM缓冲（259200字节），仍为脏区域partial更新；避免原50行绘图分块切开48px宠物及其旧位置。每次脏刷新只在首个flush前等一次GPIO18 TE新边沿，沿用已安装Espressif适配器按空闲电平选边沿的方法；最多等待25ms，缺信号后继续绘图、退避1秒再试。不会因TE缺失无限等待。该策略仍需实机确认TE边沿、扫描/传输相位和多宠物负载下的效果，不能保证所有更新都无撕裂。

每30秒记录按下/松开数、队列溢出、I2C错误、TE边沿/超时及最长刷新耗时，计数读取有跨任务保护。待真机验收：多个页面单击/连续点击、按住一秒、关屏期间按住再唤醒；单宠/多宠移动和页面切换；观察TE计数是否增长、misses/I2C错误是否持续增加。电脑测试不覆盖电气噪声、物理触控灵敏度和真实扫描相位。


## 长按实体 BOOT 导航（v0.33.64，替代v0.33.50触屏返回）

用户在确认实装3.7V／500mAh／4.2V电池后，明确要求加入并刷入固件，授权本机容量修正，覆盖此前对这项操作的只读限制。其他电池模型／校准／保护与充电器设置仍不改。依据TI SLUUBD4A §1.1.10、§6.1，开机在显示锁外检查BQ27220设计容量；已为500mAh时跳过配置，保留后续学习得到的满充容量。电池不存在时不写；传输／初始化／配置失败时显示未知SOC并记录诊断，避免继续显示失配百分比。

每15秒继续原四个只读命令；开机及每60秒记录真实SOC／电压／瞬时和平均电流／温度／剩余容量／满充及设计容量／状态位，均在显示锁外、有界I²C超时。百分比仍是芯片的估算，校正容量不能代替电芯曲线标定或完整充放电学习；不承诺首次估算即达到标定精度。手册与来源哈希见docs/hardware/battery500-source.json。


### v0.33.63 实机配置流程修正

实测确认芯片原为UNSEALED，可直接进入CONFIG UPDATE，无需FULL ACCESS。33字节长写触发I²C超时，改为官方板卡驱动相同的短MAC事务：0x3E写地址0x929D及四个容量字节，等待10ms，0x60写对应校验和与长度8，再等待10ms。读回仍核对整块32字节，除四个容量字节外必须全部保持。中断后遗留的CONFIG UPDATE先有界退出再重试。

实测EXIT_CFG_UPDATE_REINIT清除配置位后，标准FCC读数仍短暂保持3000mAh；随后实际刷新为500mAh。最终固件每100ms检查一次，最多等待3秒，避免过早误判；失败仍显示未知电量。延迟15次采样、超时、各I²C传输失败和回滚均有主机测试。配置只改本机500mAh RAM容量，原OTP、化学曲线、充电器和保护设置保持。
