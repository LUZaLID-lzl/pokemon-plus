# 钓鱼

APP 第一页「钓鱼」进入完整像素池塘。

- 陪钓伙伴从仓库选择，排除场景内伙伴；按个体持续保存，返回和重启不重置。可主动更换或「暂不陪钓」。当前陪钓者仍在仓库，需先更换才能上场或放生。移动其他个体或改名不会选错伙伴；没有仓库伙伴也能正常抛竿。
- 27种独立像素鱼，常见／少见／稀有／珍奇四档。图鉴固定编号、6只一页、共5页；未捕获显示剪影与问号，详情显示外观、捕获次数、基础金币与概率。捕获次数永久保存。
- 抛竿免费，等待6–10秒；咬钩后6秒内收竿，指针每2秒往返一次。距目标中心≤18成功、≤10良好、≤4精准；超出或超时无奖励。
- 成功后按权重抽鱼，金币为基础奖励＋良好5／精准10。四档良好权重倍率100／120／150／175，精准100／150／250／400，归一化后抽取。收竿精度提升稀有鱼机会。
- 查看图鉴或选宠、灭屏暂停本局，两种暂停叠加时也不提前恢复；返回池塘／亮屏从原进度继续。离开钓鱼取消未完成的一局。金币与捕获次数仅入账一次；金币满仍记录捕获。

`assets/fish-catalog.json`为目录来源，`tools/fishing_art.py`同步生成C／Web数值、96×64鱼图和48×32缩略图。原图由MobiIoT生成，模型、提示词、次数与哈希见`assets/fishing-generation.json`。按完整连通鱼形提取，避免网格截断鱼鳍；alpha≥200、鱼形24×16／15色加二值透明、最近邻整数放大。

池塘水纹、鱼影、浮漂、竿线和陪钓宠物动作使用唯一33ms（约30.3帧/秒）定时器与常驻资源；仅导航时创建子页对象，帧内不读图、不创建对象。主操作y260、返回y298，选宠与图鉴使用共享左右箭头。

存档v15在冻结v14前缀后追加陪钓索引与27个uint32捕获计数；v12／v13／v14迁移新增为0，保留精华／仓库／每日摸头等原进度。Web使用独立试玩存储，选宠与奖励原子提交；存储失败回滚，并允许重试同一鱼种抽取。

池塘与54张鱼图／缩略图启动一次无损解压，C与Python白名单同步；原5MiB池保持，宠物帧仍为Flash原生映射。0.33.43共16058图／15118387字节，134图解码5062216字节，含工作区仍低于5MiB；assets分区余20429字节。

完整核心／Web、27鱼穷举权重／精度／回绕／饱和、仓库个体及v14迁移／v15往返、配额失败、原生真实指针／叠加暂停／五页图鉴／零新增读图、151形态／316技能smoke、资源／字体、ESP资源分支及RGB565圆边通过。Tabbit桌面1440与手机390实际选宠／捕获／重载／图鉴27项／主动取消及存储恢复通过，无脚本HTTP错误与横溢出。
