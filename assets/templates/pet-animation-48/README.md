# 原画一致的宠物动作模板

001为首个完整样例，身份来源assets/pokemon/gen1-001-009/001.png。六动作×八姿态，48×48原生PNG，主体≤40px、最多16色、透明背景、1px深蓝黑连续外缘；允许真实关节变化，禁止整只拉伸或切割拼接模拟动作。

## 统一动作

| 动作 | 八阶段 | 播放 |
|---|---|---|
| idle | 常态→吸气→吸气顶点→呼气→闭眼→闭眼→睁眼→常态 | 140ms/帧 |
| walk | 对角腿接触→下压→经过→抬步→反侧接触→下压→经过→抬步 | 约12fps |
| happy | 预备→起跳→上升→顶点→下降→接地→缓冲→常态 | 90ms/帧 |
| eat | 低头→张嘴→咀嚼→咀嚼→吞咽→抬头→缓冲→常态 | 130ms/帧 |
| sleep | 闭眼伏卧的一个缓慢呼吸循环 | 240ms/帧 |
| attack | 蓄力→支撑→前倾→伸展→前冲→回收→缓冲→常态 | 70–130ms/帧 |

## 生成和导出

1. 始终把assets/pokemon中的对应原画作为唯一角色身份参考，禁止只凭名字重画。001专用提示词见sample-001.txt。
2. 每只按自然身体结构改写动作：四足交替迈腿；鸟类迈步/振翅；虫蛹轻摆；蛇类收放盘身。不强迫没有腿的宠物迈腿，不擅自添加肢体。
3. 每行一个动作、8列；先验收48个透明连通主体及行列顺序。按真实alpha边界切图，禁止盲目等分裁切。
4. 全图共用一个缩放系数和原画色板；脚底基线固定；跳跃只允许≤3px整体高度变化，攻击≤2px前移。睡姿保持自然低矮，不能单独放大到站姿高度。
5. 导出48个原生PNG、左右镜像、384×288图集、联系表、六个GIF、带逐帧/速度/暂停/庭院巡游的离线HTML、SHA256清单。
6. 逐帧检查种子/尾巴等附属物连接、头身比例、真实脚步、闭眼睡眠和循环首尾；同一动作不可重复八张静图冒充绘制。

## 游戏接入边界

001–009已于v0.6.8全部接入固件和Web，采用6×8帧、逐帧时长，025保留6×4帧/125ms。assets/pet-roster.json记录形态/家庭/进化阶段/图鉴编号；assets/pet-animation.json记录默认与物种覆盖规格；prepare_assets.py生成C播放契约。后续物种接入同样须更新帧导出和规格，预建全部左右描述符，验证45秒file_reads不增长，并更新内置镜像和截图。
